# overly — مدير المنتجات

إضافة Brave/Chrome جاهزة لإضافة منتجات Amazon.sa وAliExpress إلى موقع **overly | أوفرلي** دون كتابة JSON يدويًا.

## التثبيت (مرة واحدة)

1. فك ضغط ملف `saudi-deals-product-tool.zip`.
2. افتح Brave واكتب في شريط العنوان: `brave://extensions`.
   - في Chrome استخدم: `chrome://extensions`.
3. فعّل **وضع المطور** (Developer mode).
4. اضغط **تحميل إضافة غير محزّمة** (Load unpacked).
5. اختر مجلد `browser-extension` الذي يحتوي `manifest.json`.
6. ثبّت أيقونة الإضافة في شريط المتصفح.

## إضافة المنتجات

1. افتح صفحة المنتج نفسها على `amazon.sa` أو `aliexpress.com`.
2. اضغط أيقونة **overly — مدير المنتجات**.
3. راجع الاسم والصورة والسعر قبل الخصم ونسبة الخصم والتصنيف.
4. صحّح أي قيمة لم تستطع الأداة قراءتها، ثم اضغط **إضافة المنتج إلى القائمة**.
5. كرر الخطوات مع بقية المنتجات؛ القائمة محفوظة داخل المتصفح.

## تحديث الموقع

الطريقة الأسهل:

1. من الأداة اضغط **نسخ الملف وفتح GitHub للتحديث**.
2. في صفحة `deals.json` استبدل المحتوى كله بالنص المنسوخ.
3. اضغط **Commit changes**.
4. انتظر دقيقة ثم حدّث الموقع.

يمكن أيضًا تنزيل `deals.json` ورفعه يدويًا. ملف `asins.json` يضم منتجات Amazon فقط؛ أما
منتجات AliExpress فتُحفظ داخل `deals.json` مع `product_id` ورابط صفحة المنتج.

## ضوابط مهمة

- راجع البيانات قبل الإضافة؛ الأداة لا تخترع سعرًا أو خصمًا.
- لا تضف منتجًا بلا خصم حقيقي ظاهر على Amazon.sa أو AliExpress.
- السعر الحالي لا يُحفظ في الملف؛ الموقع يطلب من الزائر فتح المتجر لمعرفة السعر الحالي.
- التصنيفات المسموحة: الإلكترونيات، المنزل، الموضة.
