# Overly Product Studio V5

الإصدار 5.1.0: يحفظ بيانات التقييم والترجمة والحقول غير القابلة للتحرير، ويدمج المسودات مقارنة بآخر مزامنة لنفس المستودع. يوقف النشر عند تعارض التعديلات بدل الكتابة فوق تحديث أحدث.

إضافة Brave/Chrome متكاملة لإدارة منتجات **Amazon.sa** و**AliExpress** في موقع Overly، دون كتابة JSON يدويًا.

## ما الذي تفعله؟

- تستخرج رقم المنتج والاسم والصورة والسعر قبل الخصم ونسبة الخصم والتصنيف.
- تفحص البيانات قبل الحفظ وتمنع نشر المنتجات الناقصة.
- تميّز المنتجات: **منشور**، **تعديل محلي**، **غير منشور**، أو **يحتاج مراجعة**.
- تجلب المنتجات الحالية من الموقع بضغطة **مزامنة الموقع**.
- تنشر مباشرة إلى GitHub بعد دمج المنتجات الجديدة مع الملف الحالي؛ النشر الآمن لا يمسح المنتجات القديمة.
- تستورد وتصدر `deals.json`، وتصدر `asins.json` لمنتجات Amazon و`aliexpress_products.json` لقائمة متابعة AliExpress API.

## التثبيت

1. فك ضغط `saudi-deals-product-tool.zip`.
2. افتح `brave://extensions` أو `chrome://extensions`.
3. فعّل **وضع المطور**.
4. اضغط **تحميل إضافة غير محزّمة** واختر مجلد `browser-extension`.
5. ثبّت أيقونة Overly في شريط المتصفح.

عند تحديث إصدار سابق، استبدل ملفات مجلد الإضافة ثم اضغط **إعادة تحميل** من صفحة الإضافات.

## إضافة منتج

1. افتح صفحة المنتج نفسها على Amazon.sa أو AliExpress.
2. اضغط أيقونة **Overly Product Studio**.
3. راجع البيانات المستخرجة. أكمل أي حقل لم تستطع الصفحة توفيره.
4. اضغط **إضافة المنتج إلى القائمة**.
5. كرر ذلك مع بقية المنتجات.

السعر الحالي يُستخدم لحساب نسبة الخصم فقط، ولا يُحفظ في `deals.json` حتى لا يُعرض سعر قديم للزائر.

## المزامنة

اضغط **مزامنة الموقع** لجلب `deals.json` المنشور ودمجه مع قائمتك المحلية. لا تحتاج هذه الخطوة إلى مفتاح GitHub لأن المستودع عام.

## إعداد النشر المباشر مرة واحدة

1. في GitHub افتح **Settings → Developer settings → Personal access tokens → Fine-grained tokens**.
2. أنشئ مفتاحًا مخصصًا للمستودع `majeed3575/majeeddeals` فقط.
3. في **Repository permissions** امنح `Contents: Read and write` فقط.
4. انسخ المفتاح والصقه داخل قسم **إعداد النشر المباشر** في الأداة ثم اضغط **حفظ الإعدادات**.
5. اضغط **اختبار الاتصال**، ثم **نشر آمن إلى GitHub**.

المفتاح يُحفظ في `chrome.storage.local` داخل متصفحك فقط. لا تضعه في ملفات المشروع ولا ترسله في محادثة. يمكنك حذفه في أي وقت عبر **نسيان المفتاح**.

## كيف يحمي النشر منتجاتك؟

قبل كل نشر، تحمل الأداة أحدث `deals.json` من GitHub، وتدمج الحقول التي عدّلتها مع بيانات المنتج الكاملة. النسخ المحلية غير المعدّلة لا تستبدل التحديثات البعيدة ولا تعيد المنتجات التي حُذفت من الموقع. حذف منتج محليًا لا يحذفه من الموقع.

عند تعارض تعديل محلي مع تعديل بعيد، تتوقف العملية كلها قبل الكتابة. صدّر مسودتك احتياطيًا، واحذف النسخة المحلية المتعارضة فقط، ثم أعد المزامنة وطبّق تعديلك على البيانات الجديدة. ينطبق ذلك أيضًا عند الترقية من نسخة قديمة لا تملك سجل مزامنة مرتبطًا بالمستودع.

ملفات التصدير ونسخ JSON هي نسخ للمسودات المحلية وليست بديلًا كاملًا لكتالوج الموقع. زر فتح GitHub يعرض الملف للمراجعة؛ استخدم «نشر آمن إلى GitHub» لحفظ التعديلات. لن تظهر على الموقع إلا بعد نجاح دورة التحديث والنشر التالية.

يمكن إبقاء السعر أو الخصم صفرًا إذا لم تتوفر قيمة موثوقة. لا تُختلق قيمة لإرضاء النموذج. تبقى التقييمات والطلبات والترجمات محفوظة عند تعديل حقول أخرى؛ تغيير الاسم يلغي الترجمة القديمة كي لا تبقى مضللة.

## ضوابط مهمة

- لا تضف سعرًا أو خصمًا غير ظاهر فعليًا في المتجر.
- لا تستخدم أسماء متاجر محرّفة أو مقارنة أسعار غير موثوقة.
- حافظ على إفصاح روابط العمولة الموجود في الموقع.
- روابط Amazon تُنشأ في الموقع بوسم الشريك `faraj733-21`.
- منتجات AliExpress تحتاج رابط المنتج الحقيقي؛ لا تُنشئ الأداة روابط عمولة من دون إعداد رسمي.
