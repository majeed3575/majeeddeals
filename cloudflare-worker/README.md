# بوابة بحث AliExpress الآمنة لموقع Overly

هذه الخدمة هي الطبقة الخلفية لبحث AliExpress الشامل وللتحليلات المجمعة. تحتفظ بالمفاتيح داخل
Cloudflare Secrets، وترسل `ship_to_country=SA` في كل بحث حتى تعيد الواجهة الرسمية
المنتجات القابلة للشحن إلى السعودية فقط.

## الأسرار المطلوبة

- `ALIEXPRESS_APP_KEY`
- `ALIEXPRESS_APP_SECRET`

لا تكتب القيم داخل أي ملف. أضفها من Cloudflare: **Workers & Pages → Worker →
Settings → Variables and Secrets** واختر النوع **Secret**.

بعد النشر، انسخ رابط Worker وضعه فقط داخل `search-config.js`. رابط الخدمة ليس سراً؛
أما المفاتيح فتبقى داخل Cloudflare ولا تصل إلى المتصفح أو سجل الأخطاء.

## الحماية المطبقة

- السماح بطلبات المتصفح من نطاق موقع Overly فقط.
- قبول `GET /search` للبحث و`POST /events` للتحليلات فقط، ورفض أي مسار أو طريقة أخرى.
- تنظيف كلمة البحث وتقييدها إلى 2–80 حرفاً.
- تحديد الصفحة وحجمها ومنع الطلبات الضخمة.
- تحديد موزّع للطلبات عبر Cloudflare Rate Limiting (30 طلباً في الدقيقة لكل بصمة عميل
  مختصرة مبنية على عنوان الاتصال ونوع المتصفح، دون إرجاعها للواجهة).
- يتوقف البحث بأمان إذا غاب محدد الطلبات؛ لا يوجد مسار إنتاجي يعمل دون هذه الحماية.
- مهلة زمنية لاتصال AliExpress ومنع إظهار أخطاء المورّد أو الأسرار للزائر.
- عدم تسجيل المفاتيح أو التوقيع أو بيانات المستخدم.
- إعادة روابط عمولة رسمية وصور HTTPS فقط.
- تخزين النتائج العامة مؤقتاً لتقليل الضغط وإساءة الاستخدام.

## فهم البحث العربي

يستخدم البحث مسارين متتابعين: قاموس محلي سريع للعبارات الشائعة، ثم Workers AI فقط عندما
تبقى كلمات عربية غير مفهومة أو تصبح الترجمة عامة جداً. يولّد المسار الذكي حتى خمس عبارات
بحث إنجليزية مع الحفاظ على الماركة والموديل والأرقام. تُرفض أي صيغة عربية متبقية أو رابط
أو صيغة غير آمنة، وإذا تعذر Workers AI يعود البحث تلقائياً إلى القاموس دون تعطيل الخدمة.

لا يغيّر هذا المسار شروط الجودة: يبقى المنتج بحاجة إلى 1,000 طلب وتقييم 4.5 فأعلى، وأن يكون
متاحاً للشحن إلى السعودية، وأن يحمل رابط عمولة رسميًا من AliExpress.

## التحليلات المجمعة

يرتبط Worker بقاعدة D1 باسم `overly-analytics` من خلال الربط `ANALYTICS_DB`. أنشئ الجداول
بتطبيق الملف `migrations/0001_analytics.sql`. لا تُخزن عناوين IP أو User-Agent الخام؛ يُحفظ
نوع الجهاز بصورة عامة والدولة التقريبية ونطاق مصدر الزيارة فقط. يحذف التشغيل المجدول
السجلات الأقدم من 180 يومًا كل ليلة.
