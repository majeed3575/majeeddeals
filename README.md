## الحل الدائم: Amazon Creators API (التحديث الحيّ الرسمي)

> ⚠️ **PA-API القديمة أُوقفت نهائياً** (إيقاف رسمي 30 أبريل 2026، إغلاق السيرفر 15 مايو 2026).
> البديل الرسمي هو **Amazon Creators API** — نفس الفكرة (جلب بيانات المنتجات والأسعار برمجياً)
> لكن بمصادقة OAuth 2.0 جديدة. الكود جاهز في دالة `scrape_creators()` وينتظر مفاتيحك فقط.
> عند ضبط المفاتيح يتحوّل السكربت **تلقائياً** للتحديث الحيّ، وإلا يبقى على الوضع اليدوي.

### الشرط المسبق
Amazon تفتح Creators API فقط لحساب أسوشيتس **مقبول نهائياً** حقّق **10 مبيعات مؤهلة خلال آخر
30 يوماً**، ويجب أن يكون المسجِّل **صاحب الحساب الأساسي**.

### 1) الحصول على المفاتيح
1. ادخل Associates Central → قائمة **Tools** → **CreatorsAPI**.
2. اضغط **Create Application** → اكتب اسماً للتطبيق.
3. اضغط **Create Credential** → انسخ واحفظ فوراً (تظهر مرة واحدة فقط):
   - **Credential ID**
   - **Credential Secret**
   - **Version** (للسعودية = **3.2**، منطقة أوروبا)

### 2) إضافة المفاتيح كـ GitHub Secrets (لا تُكتب في الكود إطلاقاً)
GitHub → المستودع → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:
- `CREATORS_CLIENT_ID` = الـ Credential ID
- `CREATORS_CLIENT_SECRET` = الـ Credential Secret

قيم أخرى لها إعدادات افتراضية جاهزة للسعودية (تُغيَّر فقط عند الحاجة، كـ Secrets إضافية):
`CREATORS_TOKEN_ENDPOINT` (افتراضي `https://api.amazon.co.uk/auth/o2/token`)،
`CREATORS_MARKETPLACE` (افتراضي `www.amazon.sa`)،
`CREATORS_LANGUAGE` (افتراضي `ar_AE`؛ لو ظهر خطأ لغة اجعلها `en_AE`).

### 3) قائمة المتابعة `asins.json`
- ملف بسيط فيه قائمة الـ ASIN التي تريد متابعتها: `["B0DL5FT193", "B08FJ678YK", ...]`.
- أول تشغيلة تبذره تلقائياً من `deals.json` الحالي (لا حاجة لعمل يدوي أول مرة).
- كل تشغيلة يجلب الـ API الأسعار الحيّة لهذه المنتجات ويُظهر **فقط ما عليه خصم فعلي الآن**،
  فتظهر العروض وتختفي طبيعياً حسب توفّرها على أمازون مع بقاء قائمة المتابعة ثابتة.
- لإضافة منتجات لاحقاً: أضِف الـ ASIN إلى `asins.json` على GitHub.

**كيف تُحسب البيانات:** السعر قبل الخصم من `savingBasis` ونسبة الخصم من `savings.percentage`
(كلها بيانات أمازون الرسمية عبر OffersV2) — لا مقارنات مُختلَقة، تطابقاً مع قرارات الالتزام.

## قرارات التزام مهمة (لا تُخالَف)

هذه القرارات اتُّخذت لحماية حساب Amazon Associates من الإغلاق:

1. **لا ادعاء بوجود "كود خصم حصري"** — شاشة التحويل تقول "جاري التحقق من توفر العرض" فقط،
   لأن ادعاء كود غير موجود يُعد Misleading Claim ويعرّض الحساب للإغلاق.
2. **نافذة الخروج تعرض نسبة الخصم الحقيقية الأعلى** من البيانات، لا رقماً ثابتاً مبالغاً.
3. **السعر النهائي** يُخفى ويُستبدل بـ "اضغط لعرض السعر الحالي" — يخدم الـ CTR ويحل مشكلة
   تقادم الأسعار (سياسة أمازون تشترط أسعاراً حديثة ومؤرّخة).
4. **نص الإفصاح** في الفوتر إلزامي بموجب Operating Agreement — لا يُحذف.
5. **رابط الموقع يجب تسجيله** في حساب أسوشيتس (Account Settings → Edit your website list).
6. **أُلغيت ميزة "متوسط السوق المحلي"** بقرار المالك (2026-07-22) — تعذّر التحقق من أسعار
   السوق الحقيقية بشكل موثوق، وأي مقارنة غير متحقَّقة تُعد Misleading Claim وتعرّض الحساب للإغلاق.
   البطاقة تعرض "السعر قبل الخصم · نسبة الخصم" من بيانات المتجر الموثقة فقط.
7. **دعم AliExpress لا يعني اختلاق عروض** — لا يظهر منتج AliExpress إلا إذا أعادته الواجهة
   الرسمية برابط عمولة وصورة وبيانات صالحة، مع فرض بلد الشحن `SA` في كل طلب.

  "discount_percent": 32,
  "original_price": 379,
  "category": "الإلكترونيات"

التنظيف والمنظفات، الأزياء والأحذية، المطبخ والأجهزة المنزلية، الأثاث والديكور، المنزل،
السيارة، السفر، الرحلات والبحر والتخييم، الحدائق والزراعة، الجمال والعناية، الصحة والعناية،
البقالة والمشروبات، الرياضة، الأطفال، الألعاب، الحيوانات الأليفة، الأدوات والهوايات،
الترفيه المنزلي، المدرسة والقرطاسية، الكتب والمكتب، الساعات والمجوهرات، وتسوق متنوع.

منتج AliExpress يستخدم البنية نفسها مع `"store": "aliexpress"`، ويستبدل `asin` بـ
`product_id` ويضيف `url` كرابط عمولة رسمي من `s.click.aliexpress.com` أو كرابط API يحمل
علامات `aff_fcid` و`aff_trace_key` و`aff_platform`. رابط المنتج المباشر يُرفض ولا يُنشر.

## ربط AliExpress Affiliates API

تم تجهيز الربط الخلفي الآمن. صفحة الرجوع المسجلة في بوابة AliExpress هي:

`https://majeed3575.github.io/majeeddeals/aliexpress-callback.html`

بعد إنشاء التطبيق والموافقة عليه، أضف القيم التالية في GitHub من:
**Settings → Secrets and variables → Actions → New repository secret**:

- `ALIEXPRESS_APP_KEY`
- `ALIEXPRESS_APP_SECRET`
- `ALIEXPRESS_TRACKING_ID`

لا تضع هذه القيم في `index.html` أو `deals.json` أو إضافة المتصفح. عند توفر الأسرار الثلاثة
يُفعّل المسار تلقائياً، ويستخدم بوابة HTTPS الرسمية، ويجلب السعر والخصم بعملة USD المدعومة
ثم يحول السعر إلى الريال بسعر الربط الرسمي 3.75، ويولّد رابط العمولة الرسمي ثم يدمج المنتج
مع عروض Amazon دون حذف العروض القديمة.

### البحث الشامل الآمن داخل AliExpress

خانة البحث في الموقع لا تقتصر على قائمة `deals.json`: ترسل كلمة الزائر إلى بوابة خلفية
منشورة على Cloudflare Workers، والبوابة توقع الطلب سرياً ثم تبحث في كتالوج AliExpress
بالكامل. كل طلب يفرض `ship_to_country=SA`، لذلك لا تُعاد للواجهة إلا النتائج التي تقبل
AliExpress البحث عنها للشحن إلى السعودية وقت الطلب.

لا يجوز استدعاء AliExpress مباشرة من `index.html` لأن توقيع الطلب يحتاج App Secret، ووضعه
في المتصفح أو GitHub يسرّبه لأي زائر. لذلك تُضاف `ALIEXPRESS_APP_KEY` و
`ALIEXPRESS_APP_SECRET` مرة ثانية داخل **Cloudflare Worker Secrets** فقط، ولا تُكتبان في
ملف. أما `search-config.js` فيحتوي رابط Worker العام وحده؛ وهذا الرابط ليس سراً.

الحماية المطبقة تشمل: السماح لنطاق Overly فقط، تنظيف كلمة البحث، حد 24 نتيجة للطلب و20
صفحة للبحث، تحديد موزّع بمعدل 30 طلباً في الدقيقة لكل بصمة عميل مختصرة، مهلة اتصال، تخزين مؤقت،
رفض الروابط والصور غير المشفرة أو غير التابعة لـ AliExpress، وعدم إظهار أخطاء المورّد أو
المفاتيح أو التوقيع للزائر. شفرة البوابة وإعدادات نشرها محفوظة في مستودع خلفي خاص.

### الاكتشاف الآلي وقائمة المتابعة

العمل الآن **آلي وشامل للفئات الرائجة**: في كل تشغيل يستدعي الروبوت واجهة
`aliexpress.affiliate.product.query` المتاحة للتطبيق عبر أكثر من 100 بحث مرتب بالمبيعات.
لا ينحصر في التقنية وLife Hacks؛ بل يشمل كذلك الأزياء والأحذية والجمال والعناية والرياضة والأطفال
والحيوانات الأليفة والأدوات والهوايات والمنزل والسيارة والسفر والترفيه المنزلي، بما فيه
بروجكترات BYINTEK وتلفزيونات TCL، إضافة إلى المنتجات الأعلى سعراً.
ثم يرتّب المرشحين بدرجة تعطي الأولوية لعدد المبيعات والتقييم ووضوح الصلة، من دون إدخال
نسبة الخصم في قرار الاختيار. ويمنع المنتجات الحساسة والخردة والنسخ المتشابهة، ثم يستهدف
حتى 1000 منتج متنوع وقابل للشحن للسعودية. يغطي كل اتجاه رائج أولاً، ثم يسمح بحد أقصى
24 بديلاً مختلفاً منه لزيادة عدد المنتجات من دون نسخ متطابقة. يفحص حتى أربع صفحات
من كل بحث، ويعرض الموقع أول 24 منتجاً ثم يحمّل الدفعات التالية تلقائياً
أثناء النزول في الصفحة، ليبقى سريعاً على الجوال من دون الحاجة إلى أي زر.

الخصم ليس شرطاً للاختيار. لا يُقبل المنتج إذا كان تقييمه أقل من 90٪ أو مفقوداً، أو كانت
مبيعاته أقل من 1000، أو لم يكن سعره الحالي ضمن نطاق 10–5000 ر.س، أو لم يرجع له API سعراً
ورابط عمولة رسميين. المنتج غير المخفّض يظهر بوسم «رائج» وعدد مبيعاته بدلاً من ادعاء خصم.
يتم تدوير المنتجات المكتشفة
آلياً وإزالة المنتجات العامة القديمة عندما لا تعود ضمن الاختيار، بينما تبقى المنتجات
التي اختارها المالك يدوياً محفوظة.

إذا أردت إضافة منتجات محددة بجانب الاكتشاف الآلي، أضفها إلى
`aliexpress_products.json` بإحدى الصيغتين:

```json
{
  "products": [
    "https://www.aliexpress.com/item/1005000000000000.html",
    {
      "product_id": "1005000000000001",
      "category": "الإلكترونيات"
    }
  ]
}
```

قائمة `aliexpress_products.json` مخصّصة لاختيارات المالك اليدوية فقط؛ لا ينسخ الروبوت
إليها النتائج المكتشفة آلياً، حتى يستطيع تدوير المنتجات القديمة وحذفها عند تغيّر الجودة.
يمكن تعطيل الاكتشاف الآلي عبر `ALIEXPRESS_AUTO_DISCOVERY=false`، أو الرجوع للبحث العام
عبر `ALIEXPRESS_FOCUS_DISCOVERY=false`، وتعديل حد المنتجات
والجودة عبر `ALIEXPRESS_AUTO_LIMIT` و`ALIEXPRESS_MAX_PER_ANGLE` و
`ALIEXPRESS_QUERY_PAGE_SIZE` و`ALIEXPRESS_QUERY_PAGES` و`ALIEXPRESS_AUTO_MIN_VOLUME` و
`ALIEXPRESS_AUTO_MIN_RATING` و`ALIEXPRESS_AUTO_MIN_PRICE_SAR` و
`ALIEXPRESS_AUTO_MAX_PRICE_SAR`. لا يُنشر أي منتج لا يعيد له API رابط عمولة رسمياً وسعراً
صالحاً.

## لوحة الإدارة وحقوق الموقع

أضيفت صفحات مستقلة للخصوصية وشروط الاستخدام وإفصاح العمولة وحقوق الملكية، مع روابط ثابتة
في تذييل الموقع. اسم وهوية **أوفرلي | Overly** ومحتوى وتصميم الموقع مذكورة كحقوق للمشروع،
مع إبقاء العلامات التجارية والصور والبيانات الأصلية مملوكة لأصحابها.

لوحة الإدارة تعمل كـWorker مستقل، وشفرتها محفوظة في المستودع الخلفي الخاص ولا تظهر للعامة. الدخول محمي بواسطة
Cloudflare Access لبريد المالك فقط، ثم يعيد الخادم التحقق من توقيع Access قبل السماح بأي
قراءة أو تعديل. من اللوحة يمكن إضافة المنتجات اليدوية وتعديلها وحذفها، وكل حفظ ينشئ commit
قابلاً للمراجعة في GitHub. لا يصل مفتاح GitHub إلى المتصفح.

## لوحة تحليلات الزيارات والنقرات

يسجل الموقع عبر `POST /events` حدثين مجمعين فقط: مشاهدة الصفحة والضغط على رابط منتج. تُخزن
الأحداث في قاعدة Cloudflare D1 باسم `overly-analytics` وتظهر داخل لوحة الإدارة في مؤشرات
7 و30 و90 يومًا: الزيارات، النقرات، CTR، النشاط اليومي، المنتجات الأكثر نقرًا، التصنيفات،
المتاجر، الأجهزة، الدول ومصادر الزيارة.

لا يُحفظ عنوان IP ولا ملف تعريف دائم ولا Cookie تحليلي. يُستخدم عنوان الاتصال لحظيًا فقط
داخل محدد الطلبات ثم لا يُكتب في القاعدة. تُحذف سجلات التحليلات تلقائيًا بعد 180 يومًا،
وتشرح `privacy.html` هذه المعالجة بوضوح.

## تحسين الظهور في محركات البحث (SEO)

أضيف مولّد ثابت باسم `generate_seo.py`. بعد كل تحديث للمنتجات ينشئ تلقائياً:

- صفحة مستقلة لكل منتج محفوظ، بعنوان ووصف وCanonical وبيانات `Product` و`BreadcrumbList`.
- صفحات تصنيفات ومتاجر مقسمة إلى صفحات فعلية بروابط `prev` و`next` قابلة للزحف.
- خمسة أدلة شراء أصلية، وصفحات «عن أوفرلي» و«منهجية الاختيار» وصفحة 404.
- `sitemap.xml` يحتوي الروابط الفعلية فقط و`lastmod` يتغير عند تغير محتوى الصفحة.
- `deals-initial.json` خفيف للظهور الأول؛ بعدها تُحمّل القائمة الكاملة في وقت خمول المتصفح.

روابط Amazon وAliExpress التجارية موسومة `rel="sponsored noopener noreferrer"`. لا تضع
الصفحات سعراً حالياً في البيانات المنظمة، ولا تنشئ مراجعات أو أعداد تقييمات غير موجودة.
أما البحث المباشر في AliExpress فلا يُفهرس؛ الفهرسة للمنتجات المحفوظة في `deals.json` فقط.

ملف GitHub Actions يشغّل المولّد بعد `scraper.py` كل ساعة، ويحتفظ بحالة صغيرة في
`seo-state.json` حتى لا تتغير تواريخ مئات الصفحات إذا لم تتغير بياناتها فعلياً. العنوان
الرئيسي في الصفحة الرئيسية يبقى كما قرره المالك: «العرض الصح. أوفر عليك.»

لإكمال Search Console اتبع [SEARCH-CONSOLE.md](SEARCH-CONSOLE.md). إثبات الملكية يحتاج
رمزاً حقيقياً من حساب Google ولا يجوز إنشاء رمز افتراضي. الدومين الخاص تحسين اختياري؛ لا
يُضاف ملف `CNAME` قبل امتلاك اسم الدومين فعلياً حتى لا تتوقف GitHub Pages.

## تيليجرام (جاهز للتفعيل)

يدعم `scraper.py` النشر لقناة تيليجرام من Amazon وAliExpress بصورتين:

- نشر المنتج الجديد فور اكتشافه في التحديث الساعي، مع قائمة انتظار آمنة إذا وصلت عدة منتجات.
- نشر منتج مميز واحد كل ساعتين، بحد أقصى 10 منتجات مميزة يومياً، مع أولوية التنوع والجودة.
- كل منشور يتضمن صورة، عنواناً ووصفاً عربياً مبنياً على بيانات الموقع، التصنيف والمتجر
  والطلبات والخصم والسعر المرجعي عند توفرها، وزر عرض المنتج وإفصاح رابط العمولة.
- منع إعادة المنتج نفسه مدة 7 أيام، وحفظ الحالة في `posted_deals.json`.
- يمكن تشغيل منشور تجريبي من `Actions → Overly Deals Updater → Run workflow` مع تفعيل
  خيار `telegram_digest`.

للتفعيل: أنشئ البوت عبر BotFather، أضفه مشرفاً إلى القناة، ثم أضف سرّين في
`Settings → Secrets and variables → Actions`:
`TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHANNEL_USERNAME`. اكتب اسم القناة العامة بصيغة
`@channel_name` أو معرّف القناة الخاص الذي يبدأ عادةً بـ`-100`. لا تضع رمز البوت داخل
أي ملف في المستودع.
