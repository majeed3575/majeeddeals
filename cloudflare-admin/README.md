# لوحة بيانات أوفرلي الآمنة

لوحة خاصة للمالك تعرض إحصاءات الموقع والمنتجات الأكثر نقرًا. اللوحة **للقراءة فقط** ولا تستطيع تعديل أو حذف المنتجات أو الكتابة إلى GitHub.

## ما تعرضه

- زيارات الموقع ونقرات المنتجات ومعدل CTR.
- أرقام اليوم والفترات 7 و30 و90 يومًا.
- رسم يومي للزيارات والنقرات.
- المنتجات والتصنيفات والمتاجر الأكثر نقرًا.
- الأجهزة والدول ومصادر الزيارات.
- تحديث تلقائي للواجهة كل دقيقة.

## الخصوصية

يسجل عامل البحث أحداثًا مجمعة فقط في D1. لا يُخزن عنوان IP، ولا User-Agent الكامل، ولا البريد، ولا أي معرّف شخصي. تُحذف السجلات الأقدم من 180 يومًا تلقائيًا.

## الحماية

الدخول يعتمد على Cloudflare Access والتحقق من JWT داخل العامل. يجب إضافة القيم التالية كأسرار أو متغيرات آمنة في إعدادات العامل، ولا توضع في GitHub:

- `ADMIN_ALLOWED_EMAIL`: بريد المالك المسموح له.
- `TEAM_DOMAIN`: رابط فريق Cloudflare Access مثل `https://team.cloudflareaccess.com`.
- `POLICY_AUD`: Audience الخاص بتطبيق Access.

لا يحتاج هذا العامل إلى GitHub Token.

## النشر

```bash
npm ci
npx wrangler deploy --keep-vars
```

بعد النشر، أنشئ تطبيق Cloudflare Access من نوع Self-hosted، واربطه بعنوان `overly-admin.workers.dev`، ثم اسمح لبريد المالك فقط.
