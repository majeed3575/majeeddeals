# لوحة بيانات أوفرلي الآمنة

لوحة خاصة للمالك تعرض إحصاءات الموقع والمنتجات الأكثر نقرًا. اللوحة **للقراءة فقط** ولا تستطيع تعديل أو حذف المنتجات أو الكتابة إلى GitHub.

## ما تعرضه

- زيارات الموقع ونقرات المنتجات ومعدل CTR.
- أرقام اليوم والفترات 7 و30 و90 يومًا.
- رسم يومي للزيارات والنقرات.
- المنتجات والتصنيفات والمتاجر الأكثر نقرًا.
- الأجهزة والدول ومصادر الزيارات.
- تحديث تلقائي للواجهة كل دقيقة.

## الخصوصية

يسجل عامل البحث أحداثًا مجمعة فقط في D1. لا يُخزن عنوان IP، ولا User-Agent الكامل، ولا البريد، ولا أي معرّف شخصي. تُحذف السجلات الأقدم من 180 يومًا تلقائيًا.

## الحماية

الدخول يعتمد على **Worker-level Cloudflare Access**. الحماية مرتبطة بالعامل نفسه، ولذلك تشمل رابط الإنتاج وكل روابط المعاينة حتى لو تغيّرت عناوين العامل.

- النطاق: كل حركة العامل `All traffic`.
- السياسة: أعضاء حساب Cloudflare فقط.
- مدة الجلسة: ساعة واحدة.
- داخل الكود يتم رفض الطلب ما لم يوفّر Cloudflare هوية موثقة عبر `ctx.access`.

لا يحتاج هذا العامل إلى GitHub Token أو كلمة مرور مخزنة في GitHub.

## النشر

```bash
npm ci
npx wrangler deploy --keep-vars
```

بعد النشر، فعّل الحماية من **Workers & Pages → overly-admin → Access** واختر **All traffic** وسياسة **Cloudflare account**. يُنصح بتفعيل المصادقة الثنائية على حساب Cloudflare.
